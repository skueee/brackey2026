# The House

## Playing

- WASD/ZQSD/Arrows : Move

- E : Interact

- Enter : Select

- Shift : Next Dialogue



## Project strcture

```
addons/                      The addons
    godot-super-wakatime     Wakatime plugin for Hackatime
assets/                      The assets
blender/                     Blender files (not intended for in-game use)
materials/                   Some of the materials
scenes/                      The scenes
    game.tscn                The main scene
    main_door.tscn           The entrance door
    map.tscn                 The walls
    player.tscn              The player controller
    dialog.tscn              The dialogs
    end.tscn                 The good end screen
    gameover.tscn            The bad end screen
    hud.tscn                 The players HUD
    inventory_view.tscn      The inventory view used for some mechanics
scripts/                     The scripts
    characters/              The strangers description
    objects/                 The objects description
```

There is more files, but they are not important to explain
